# Kyaw Naing Soe - Portfolio

A responsive personal portfolio for Kyaw Naing Soe, presenting nearly nine years of software engineering experience and an emerging transition into content creation.

## Preview locally

```bash
python3 -m http.server 4173 -d dist
```

Then open `http://localhost:4173`.

## Structure

- `dist/index.html` - page content and semantic structure
- `dist/styles.css` - responsive visual system and motion
- `dist/script.js` - navigation and reveal interactions
- `dist/assets/kyaw-naing-soe.jpg` - optimized profile image
